# اعتبارسنجی روی داده حسگر واقعی عمومی

## محدودیت‌ها (مهم)
- نمونه آزمایشگاهی/حسگر ثابت با خوردگی یکنواخت تقریباً خطی؛ **تجهیز صنعتی، خوردگی موضعی (pitting)، نقاط CML متعدد و بازرسی دستی نیست**.
- افق پیش‌بینی چند روز تا چند ماه است، نه ۵ سال؛ تعداد نمونه ارزیابی کم است (n ≤ ۱۵).
- بازه‌های اطمینان بیش‌ازحد محافظه‌کارند (پوشش ۱۰۰٪) چون σ اندازه‌گیری مدل (۰٫۲۵ mm) برای UT دستی است، نه حسگر ثابت (نویز درون‌روزی ≈ ۰٫۰۰۲ mm).
- **نتیجه:** منطق نرخ/پیش‌بینی روی داده حسگر واقعی بهتر از خط پایه عمل می‌کند — شاهد پشتیبان TRL 4، نه TRL 5.
- مدل عیب NDT با این داده قابل آزمون نیست (برچسب عیب ندارد). داده TOF دوم (Zenodo 4280715، نمونه ثابت) فقط نویز حسگر را نشان می‌دهد.
