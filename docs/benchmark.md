# بنچ‌مارک با سامانه‌های بین‌المللی

> **روش و محدودیت:** این یک مقایسه **قابلیتی** بر پایه صفحات عمومی فروشندگان و منابع ثانویه است؛ **بنچ‌مارک عملکردی (دقت/سرعت روی داده یکسان) نیست**، چون این سامانه‌ها نسخه آزمایشی عمومی یا داده مشترک ندارند. ادعاهای فروشندگان بازاریابی‌اند و مستقل راستی‌آزمایی نشده‌اند. نتیجه ستون «سامانه ما» از خود کد و تست‌های این مخزن آمده است.

## جمع‌بندی
- **نقاط قوت ما:** یکپارچگی تحلیل سیگنال NDT با پیش‌بینی خوردگی و ریسک در یک محصول؛ رابط فارسی؛ استقرار آفلاین/On-Premise؛ شفافیت مدل (کارت مدل، بک‌تست، Audit Trail).
- **شکاف‌ها نسبت به رقبا:** نسخه‌های ما از API 581/IOW/FFS/CUI و اتصال CMMS/DCS **جزئی و غیرگواهی‌شده** هستند ([docs/ENGINEERING.md](ENGINEERING.md))؛ همچنین فرمت‌های بومی دستگاه‌ها، گواهی‌ها و تجربه میدانی. این‌ها پیش‌نیاز ورود به مقایسه مستقیم تجاری‌اند.
- **ملاحظه صداقت:** دقت مدل‌های ما فقط روی داده مصنوعی و یک مجموعه حسگر عمومی سنجیده شده ([اعتبارسنجی](validation-public-data.md)) و با عملکرد میدانی محصولات بالغ قابل مقایسه نیست.

## گام‌های بعدی پیشنهادی (به ترتیب اولویت)
1. آزمون آداپتورها روی SAP PM/Maximo/PI واقعی (محیط تست مشتری) و ورود دوطرفه وضعیت دستور کار.
2. جایگزینی جداول پارامتریک API 581 با جداول مجاز و تأیید توسط کارشناس RBI؛ تعریف حدود IOW واقعی.
3. پایلوت با داده واقعی یک واحد ([docs/PILOT](PILOT)) و مقایسه رتبه ریسک ما با خروجی نرم‌افزار موجود همان واحد.
